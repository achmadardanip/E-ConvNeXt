# E-ConvNeXt Quick Start Guide

## 🎯 Get Started in 5 Minutes

This guide helps you quickly start training E-ConvNeXt models for image classification or object detection.

## Prerequisites

- **GPU**: NVIDIA RTX 3050 or similar (4GB+ VRAM)
- **CPU**: Intel i7 or equivalent
- **RAM**: 16GB+ recommended
- **Python**: 3.8+
- **OS**: Linux/Windows with CUDA support

## Installation

### 1. Clone Repository

```bash
git clone https://github.com/achmadardanip/E-ConvNeXt.git
cd E-ConvNeXt
```

### 2. Create Environment

```bash
conda create -n econvnext python=3.8 -y
conda activate econvnext
```

### 3. Install PaddlePaddle

**For NVIDIA GPU (CUDA 11.2+):**
```bash
python -m pip install paddlepaddle-gpu -i https://mirror.baidu.com/pypi/simple
```

**For CPU only:**
```bash
python -m pip install paddlepaddle -i https://mirror.baidu.com/pypi/simple
```

### 4. Install Dependencies

```bash
cd classification
pip install -r requirements.txt
cd ..
```

## Prepare Your Dataset

### For Classification:

**Option 1: Use the helper script**
```bash
python prepare_dataset.py \
    --task classification \
    --root-dir /path/to/your/images \
    --output-dir dataset/custom_dataset \
    --train-split 0.8
```

**Option 2: Manual preparation**

Create directory structure:
```
dataset/custom_dataset/
├── images/
│   ├── class1/
│   │   ├── img1.jpg
│   │   └── img2.jpg
│   └── class2/
│       ├── img1.jpg
│       └── img2.jpg
└── [generated by script]
    ├── train_list.txt
    ├── val_list.txt
    └── class_names.txt
```

### For Detection:

Use COCO format:
```
dataset/coco_format/
├── annotations/
│   ├── instances_train.json
│   └── instances_val.json
└── images/
    ├── train/
    └── val/
```

**Annotation Tools:**
- [LabelImg](https://github.com/heartexlabs/labelImg) - Easy to use
- [CVAT](https://github.com/opencv/cvat) - Professional grade
- [VIA](https://www.robots.ox.ac.uk/~vgg/software/via/) - Browser-based

## Model Architectures

Choose based on your needs:

| Model | Parameters | FLOPs | Accuracy | Speed (RTX 3050) | Use Case |
|-------|-----------|-------|----------|------------------|----------|
| **E-ConvNeXt-mini** | 7.6M | 0.9G | 78.3% | ~180 FPS | Fast inference, mobile |
| **E-ConvNeXt-tiny** | 13.2M | 2.0G | 80.6% | ~130 FPS | Balanced |
| **E-ConvNeXt-small** | 19.4M | 3.1G | 81.9% | ~100 FPS | Maximum accuracy |

**Recommendation for RTX 3050:**
- **Start with**: E-ConvNeXt-mini
- **Upgrade to**: E-ConvNeXt-tiny if accuracy is insufficient
- **Use**: E-ConvNeXt-small only for offline inference (slower training)

## Training Tips for RTX 3050

### Optimal Batch Sizes:

| Task | Model | Batch Size | Expected Training Time* |
|------|-------|-----------|------------------------|
| Classification | mini | 32-64 | 2-3 hours |
| Classification | tiny | 24-32 | 3-4 hours |
| Classification | small | 16-24 | 4-5 hours |
| Detection | mini | 8-16 | 4-6 hours |
| Detection | tiny | 4-8 | 6-8 hours |

*For 50 epochs on ~10K images

### If You Run Out of Memory:

```python
# In notebook (Section 2):
BATCH_SIZE = 16  # Reduce from 32
IMAGE_SIZE = 192  # Reduce from 224
NUM_WORKERS = 2  # Reduce from 4

# Or in command line, edit config YAML:
# DataLoader.Train.sampler.batch_size: 16
```

### Speed Up Training:

1. **Use mixed precision** (automatic in notebook)
2. **Reduce image size** for faster epochs
3. **Use data augmentation** instead of more epochs
4. **Enable GPU memory optimization**:
   ```python
   import paddle
   paddle.device.set_device('gpu:0')
   paddle.device.cuda.empty_cache()
   ```

## Common Issues

### Issue: "CUDA out of memory"
**Solution**: Reduce batch size or image size

### Issue: "Dataset not found"
**Solution**: Check paths in configuration, ensure files exist

### Issue: "Slow training"
**Solution**: 
- Check GPU is being used: `nvidia-smi`
- Reduce num_workers if CPU is bottleneck
- Use smaller model (mini instead of small)

### Issue: "Low accuracy"
**Solution**:
- Train for more epochs (100+)
- Use data augmentation
- Try larger model (tiny/small)
- Check dataset quality

### Issue: "ImportError: paddle"
**Solution**: 
```bash
pip install paddlepaddle-gpu -i https://mirror.baidu.com/pypi/simple
```
